# 瑟琳娜動作更新

七組四幀動作：待機、普攻、跑步、格擋、受擊、技能動作、倒下。選角頁點瑟琳娜可切換、逐幀查看與重播；尚未開放出戰，未設定技能效果。

24 張新影格以原尺寸無損 WebP 交付，保留透明度。來源的完整劍身跨格時依連通輪廓分離，不以固定網格截斷。每組採固定縮放與明確腳底定位，動畫註冊包含左右手與武器驗收雜湊。

驗證：七項相關測試通過、Sprite 驗證 0 錯誤；既有 125 項歷史 review finding 未改動。桌面瀏覽器確認動作頁籤、單幀顯示、完整突刺、倒下末幀與控制按鈕可見。

發布沿用 v387 的雜湊綁定 Release，先驗證原包，再套用 site-updates-manifest.json 中逐檔驗證的覆蓋檔案。部署前已以實際 Release 測試，合併結果與本機建置全部檔案逐一相同，另保留 .nojekyll。

這裡的匯入腳本與測試是開發來源專案的輔助檔，應放回其 scripts/ 與 tests/ 目錄使用。匯入腳本可傳入生成圖目錄，或沿用來源專案 source-assets/swordsman-actions-v2/ 中已有的原始圖集；不會重新生成圖片。
