# 瑟菲娜：四張機制牌與型態外觀草案

已加入告解（0 費綠）、聖言：止（1 費藍）、無聲彌撒（1 費紫）、末日鐘聲（2 費紫）。可透過既有牧師卡池、商店與訓練場選牌取得。

- 告解先選另一張手牌；選擇期間戰鬥暫停，可取消。確認後棄牌、祈願 +2，棄牧師卡抽一張。本次打出的告解從戰鬥牌堆移除，下場恢復，仍正常獲得施放牧師卡的祈願。
- 聖言：止需要目標已有施法。延後該次施法與行動時間 2 秒，並同步延後既有負面狀態到期與週期跳傷時間。一次施法只接受一次，不當作打斷。
- 無聲彌撒使用戰鬥邏輯時間倒數；其他職業出牌不取消，使用其他牧師卡取消。牧師倒下時取消；四秒完成抽二、祈願 +2。
- 末日鐘聲標記選定敵人；施放本身不計數，之後使用不同職業卡累積，重複職業不重複計數。三聲或八秒到期引爆；目標先倒下不轉移。傷害屬性在標記時決定，黑祭司為暗傷。
- 狀態保存在 auto.skills[4]，暫停、存檔續戰與新戰鬥沿用現有生命週期。
